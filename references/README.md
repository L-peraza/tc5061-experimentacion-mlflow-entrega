# Referencias del dataset

Fuente: Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Conjunto de datos]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306

Archivo utilizado: `bank-full.csv`, separador `;`, 45,211 filas y 17 columnas. La variable objetivo `y` indica la suscripción de un depósito. La descripción completa de las variables acompaña la descarga oficial. `duration` se excluye para evitar información posterior a la llamada.

Descarga: https://archive.ics.uci.edu/static/public/222/bank+marketing.zip
